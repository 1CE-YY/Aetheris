# 机器学习基础

## 1. 机器学习概述

机器学习是人工智能的一个分支，它使计算机能够在没有明确编程的情况下从数据中学习。其核心任务是构建模型，从数据中发现规律，并用这些规律对未知数据进行预测。

### 1.1 学习类型

- **监督学习**：使用标记数据训练模型
  - 分类问题（如垃圾邮件检测）
  - 回归问题（如房价预测）

- **无监督学习**：使用未标记数据发现模式
  - 聚类（如客户分群）
  - 降维（如主成分分析）

- **强化学习**：通过与环境交互学习最优策略

## 2. 线性回归

线性回归是回归分析中最基础的算法之一。它假设输入特征与输出之间存在线性关系。

### 2.1 模型形式

$$h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \dots + \theta_n x_n$$

### 2.2 损失函数

均方误差（MSE）是最常用的损失函数：

$$J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2$$

### 2.3 梯度下降

通过迭代更新参数来最小化损失函数：

$$\theta_j := \theta_j - \alpha \frac{\partial}{\partial \theta_j} J(\theta)$$

其中 $\alpha$ 是学习率。

## 3. 逻辑回归

逻辑回归广泛用于二分类问题。它使用 Sigmoid 函数将输出映射到 [0, 1] 区间。

### 3.1 Sigmoid 函数

$$g(z) = \frac{1}{1 + e^{-z}}$$

### 3.2 决策边界

当 $h_\theta(x) \geq 0.5$ 时，预测为类别1；否则预测为类别0。

## 4. 正则化

正则化用于防止过拟合，通过在损失函数中添加惩罚项实现。

### 4.1 L1 正则化（Lasso）

$$J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2 + \lambda \sum_{j=1}^{n} |\theta_j|$$

### 4.2 L2 正则化（Ridge）

$$J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2 + \lambda \sum_{j=1}^{n} \theta_j^2$$

## 5. 神经网络

神经网络是受生物神经元启发的多层模型。

### 5.1 前向传播

$$z^{[l]} = W^{[l]} a^{[l-1]} + b^{[l]}$$

$$a^{[l]} = \sigma(z^{[l]})$$

### 5.2 反向传播

通过链式法则计算梯度并更新参数。

## 6. 模型评估

### 6.1 评估指标

- **准确率** (Accuracy)：正确预测的比例
- **精确率** (Precision)：预测为正的样本中真正为正的比例
- **召回率** (Recall)：真正为正的样本中被正确预测的比例
- **F1分数**：精确率和召回率的调和平均

### 6.2 交叉验证

将数据集分成k份，每次用k-1份训练，1份验证，重复k次取平均。
